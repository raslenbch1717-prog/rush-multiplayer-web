# RUSH 3D — Ultimate Obstacle Party

A colorful 3D browser-based obstacle-race prototype inspired by party platformers. Includes bean-style characters, three selectable courses, moving/spinning hazards, keyboard and touch controls, race timer/progress, party codes and WebSocket player position sync.

## Deploy to Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Static files are served from `public/`.

## Controls
WASD / Arrow keys to move; Space to jump. Mobile has on-screen controls.

Note: Three.js is loaded from jsDelivr, so players need internet access. This is an original prototype and not an official Fall Guys game or asset pack. Multiplayer synchronizes player positions; it does not yet include authoritative physics, persistent accounts, matchmaking, or anti-cheat.
